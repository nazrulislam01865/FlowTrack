# Inquiry attachment upload UX — 2026-08-28

- Inquiry task attachment modal is now upload-only; the existing-document source option is no longer presented.
- Task attachment uploads show real Livewire upload progress with percentage and a progress track, matching the Order attachment experience.
- Create Inquiry attachment dropzone no longer shows a separate **Choose files** button; the whole dropzone and **browse files** text remain clickable.
- Create Inquiry multi-file uploads now show percentage progress while Livewire transfers files.
- Inquiry task attachment availability now follows the document-create permission because the modal no longer links existing documents.
