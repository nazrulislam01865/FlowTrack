# Billing Invoice Send Blade Parse Fix - 2026-09-04

## Issue
Opening the Billing-stage Send Invoice action could fail during a Livewire render with a Blade parse error near the recipient suggestion loop (`unexpected token endforeach`).

## Fix
- Kept invoice recipient state initialized in the modal's top-level scope.
- Replaced the To/CC suggestion loop control structures with native PHP `if`/`foreach` blocks so Livewire's extended Blade compiler does not instrument nested recipient loops incorrectly.
- Precomputed the CC suggestion's next recipient string before rendering, removing inline state-building PHP from the loop.
- Added regression assertions for the safe recipient-loop structure.
- Removed compiled Blade view cache files from the distributable archive; they are runtime artifacts and must be regenerated by Laravel.

## Deployment note
After replacing files in an existing installation, run `php artisan view:clear` once so any previously compiled view is removed.
