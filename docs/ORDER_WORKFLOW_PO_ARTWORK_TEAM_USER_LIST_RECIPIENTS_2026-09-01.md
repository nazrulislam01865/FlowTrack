# Purchase Order -> Artwork Team user-list recipients — 2026-09-01

## Change

`NEW_SEND_PO_ARTWORK` no longer sends the Purchase Order to users assigned to Artwork tasks on the current Order.

Recipients now come from **Administration > Users & role assignments**. Every active workspace user with a valid email who is configured as part of the Artwork Team is included. Membership may come from an **Artwork Team / Artwork role** or from the **Artwork / Design department**.

To preserve existing installations, the resolver accepts these normalized department identities:

- Artwork
- Artwork Team
- Design
- Design Team
- DES (legacy seeded department code)

The current `users.department_id` value and assigned user roles are read from the same Users & role assignments data. The active workspace membership department is retained as a compatibility fallback for migrated accounts. Duplicate email addresses are removed.

## Preview

The Send Purchase Order modal now labels the recipient rule as:

`Users & role assignments — Artwork Team users`

The recipient chips and recipient count are generated by the same resolver used for actual delivery, so the preview remains exact.

## Unchanged

- Purchase Order attachment resolution
- E2A / central EmailService delivery
- synchronous provider acceptance before workflow completion
- Artwork -> Order Team recipient behavior
- Order Team business-unit filtering
- workflow task completion rules

No database migration is required.
