# Order Details popup theme

Order Details popups are intentionally scoped under `.ft-order-prototype-detail` and use the same teal operational accent as the page's primary task/action buttons.

Updated surfaces include:
- workflow action modal
- task document modal
- product edit modal
- shipping edit modal
- order attention modal
- cancellation modal neutral/danger actions
- invoice/payment/collection finance modals
- reusable search-select focus/selected states inside Order Details popups

The change is presentation-only. No workflow, task, document, invoice, payment, or Livewire business logic was changed.
