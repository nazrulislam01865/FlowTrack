# My Work Personal Task Board Update

- My Work now renders as the same Operations Task Board layout used by the Board page.
- The My Work board is scoped to the currently logged-in user's assigned tasks only, even for Admin and Super Admin users.
- The My Work badge now counts only the logged-in user's open assigned tasks.
- My Work includes task board filters for Job, Client, Status, Priority, and Due Date.
- Drag-and-drop status updates work from My Work for assigned tasks and still use the existing backend task update endpoint.
- Collapsing job groups, opening tasks/jobs, and deleting tasks continue to work from the My Work board.
